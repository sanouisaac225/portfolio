# Portfolio 3D — GitHub Pages

Cette version est prête à remplacer l’ancien contenu du dépôt `portfolio`.

## Déploiement

1. Copier tout le contenu de ce dossier dans le dépôt GitHub `portfolio`.
2. Vérifier que `index.html` est à la racine.
3. Exécuter :

```bash
git add .
git commit -m "Replace old portfolio with new 3D IRST portfolio"
git push origin main
```

4. Dans GitHub : **Settings → Pages → Deploy from a branch → main → / (root)**.

Le QR code du CV pointe vers :
`https://sanouisa225.github.io/portfolio/`
